
# Sistema para hospital veterinário 🐾

Este sistema foi desenvolvido para otimizar e facilitar o dia a dia dos profissionais de um hospital veterinário, oferecendo um conjunto de ferramentas que auxiliam na gestão e no atendimento aos pacientes. O sistema permite o cadastro completo dos pacientes (animais), com informações detalhadas como nome, espécie, raça, idade e dados de contato dos tutores.

Além disso, o histórico médico de cada paciente é mantido de forma organizada, permitindo o registro de consultas, diagnósticos, tratamentos, medicações administradas e exames realizados. Isso garante uma visão clara e atualizada do quadro clínico do animal, melhorando a qualidade do atendimento e a comunicação entre os profissionais.

Com isso, o sistema contribui para a melhoria contínua dos processos internos, proporcionando um atendimento mais rápido e eficiente para os pacientes e seus tutores.

## Passo a passo para iniciar o projeto 👣

### 1. Copie o projeto na sua máquina 🔗


```` git clone https://github.com/NlsGAA/VeterinarySystem-Laravel.git ````

### 1.1 Acesse a pasta onde o projeto foi clonado 📂

```` cd nomeDaPasta ````

### 2. Faça o build do projeto 👷

```` docker compose build && docker compose up -d ````

O projeto estará rodando na porta 8000, para ter acesso a interface, acesse o projeto do [Frontend](https://github.com/NlsGAA/VeterinarySystem-Nuxtjs), onde poderá realizar as operações disponíveis de forma intuítiva.
